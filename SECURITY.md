# Security policy

Please do not report credentials, private financial records, or other
sensitive information in a public issue.

This repository contains a provider-neutral demo UI. It must not acquire,
store, or print bank, brokerage, database, cloud, or AI credentials. Private
applications should supply their own authenticated repository implementation
outside this project.

For a suspected security problem, open a private GitHub security advisory
when available or contact the repository maintainers through the GitHub
organization before providing sensitive details.
